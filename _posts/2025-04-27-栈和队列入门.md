## 什么是栈？

栈是一种 **后进先出** 的数据结构，就像一叠盘子：后放上去的盘子会先被拿走。

### 栈的基本操作
- **push**：压入元素
- **pop**：弹出栈顶元素
- **peek**：查看栈顶元素

## 什么是队列？

队列是一种 **先进先出** 的数据结构，就像排队买票：先来的人先买到票。

### 队列的基本操作
- **enqueue**：入队
- **dequeue**：出队
- **front**：查看队首元素

## 代码示例（C++）

```cpp
// 栈的实现
#include <stack>
#include <queue>

stack<int> stk;
stk.push(1);   // push
stk.pop();     // pop (弹出栈顶元素)

// 队列的实现
queue<int> que;
que.push(1);   // enqueue
que.pop();     // dequeue (弹出队首元素)
